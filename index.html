1. Penjelasan Detail: Fungsi Komposisi & Invers

A. Fungsi Komposisi adalah penggabungan operasi dua buah fungsi atau lebih secara berurutan sehingga menghasilkan sebuah fungsi baru. Operasi komposisi dilambangkan dengan tanda bundaran (∘) yang dibaca "bundaran" atau "komposisi".

Bayangkan sebuah mesin berantai: input x masuk ke mesin g terlebih dahulu menghasilkan g(x), lalu hasilnya langsung dimasukkan ke mesin f sehingga menghasilkan f(g(x)).

B. Fungsi Invers (f-1) adalah fungsi kebalikan yang memetakan kembali daerah hasil (range) ke daerah asal (domain). Suatu fungsi f(x) mempunyai fungsi invers jika dan hanya jika fungsi tersebut merupakan fungsi bijektif (korespondensi satu-satu). Jika f(a) = b, maka f-1(b) = a.

Kumpulan Rumus & Sifat Lengkap

Definisi Komposisi 2 Fungsi
(f ∘ g)(x) = f(g(x))
(g ∘ f)(x) = g(f(x))
Komposisi 3 Fungsi
(f ∘ g ∘ h)(x) = f(g(h(x)))
Sifat-Sifat Komposisi
1. Tidak Komutatif: (f ∘ g) ≠ (g ∘ f)
2. Asosiatif: ((f ∘ g) ∘ h) = (f ∘ (g ∘ h))
3. Identitas I(x)=x: (f ∘ I) = (I ∘ f) = f
Sifat-Sifat Invers & Komposisi
1. (f-1)-1(x) = f(x)
2. (f ∘ f-1)(x) = (f-1 ∘ f)(x) = x
3. (f ∘ g)-1(x) = (g-1 ∘ f-1)(x)
4. (f ∘ g ∘ h)-1 = (h-1 ∘ g-1 ∘ f-1)
⚡ Cara Cepat & Rumus Kilat Fungsi Invers
  • Invers Fungsi Linear: Jika f(x) = ax + b → f-1(x) = (x - b) / a
  • Invers Fungsi Pecahan (Rasional): Jika f(x) = (ax + b) / (cx + d), cukup tukar posisi a dan d lalu ubah tandanya (+/-):
    → f-1(x) = (-dx + b) / (cx - a)
  • Invers Fungsi Kuadrat: Jika f(x) = ax2 + bx + c → f-1(x) = [ -b ± √(b2 - 4a(c - x)) ] / 2a
  • Invers Fungsi Akar: Jika f(x) = √(ax + b) → f-1(x) = (x2 - b) / a (syarat x ≥ 0)
  • Invers Eksponen & Logaritma: Jika f(x) = ax → f-1(x) = alog(x)
  • Mencari Fungsi Awal di Depan: Jika diketahui (f ∘ g)(x) dan g(x), maka f(x) = (f ∘ g)(g-1(x)) (cukup substitusi invers g ke dalam fungsi komposisi!).

Contoh Soal & Pembahasan Bertingkat

Tingkat 1: Mudah

Soal: Diketahui f(x) = 3x - 5 dan g(x) = x + 2. Tentukan nilai dari (f ∘ g)(4)!

Pembahasan:
Langkah 1: Hitung g(4) terlebih dahulu → g(4) = 4 + 2 = 6.
Langkah 2: Masukkan hasilnya ke fungsi f → f(6) = 3(6) - 5 = 18 - 5 = 13.
Tingkat 2: Sedang

Soal: Diketahui fungsi f(x) = (2x + 3) / (4x - 5) untuk x ≠ 5/4. Tentukan rumus fungsi invers f-1(x)!

Pembahasan (Menggunakan Rumus Cepat):
Dari f(x) = (2x + 3) / (4x - 5), diperoleh a = 2, b = 3, c = 4, d = -5.
Tukar a dan d lalu ubah tandanya (-5 jadi +5, dan 2 jadi -2):
f-1(x) = (5x + 3) / (4x - 2), dengan x ≠ 1/2.
Tingkat 3: Sulit (HOTS)

Soal: Diketahui (f ∘ g)(x) = 4x2 + 8x - 3 dan g(x) = 2x + 1. Tentukan rumus fungsi f(x)!

Pembahasan (Trik Substitusi Invers):
1. Cari invers dari g(x) = 2x + 1 → g-1(x) = (x - 1) / 2.
2. Substitusi g-1(x) ke dalam (f ∘ g)(x):
f(x) = 4((x - 1)/2)2 + 8((x - 1)/2) - 3
f(x) = 4((x2 - 2x + 1)/4) + 4(x - 1) - 3
f(x) = (x2 - 2x + 1) + 4x - 4 - 3
f(x) = x2 + 2x - 6.

Latihan Mandiri (5 Soal — Opsional)

Pilih jawaban yang menurutmu paling tepat, lalu klik tombol cek untuk melihat hasil dan pembahasannya.

1. Jika f(x) = 2x + 1 dan g(x) = x2 - 3, maka (g ∘ f)(x) adalah...
2. Invers dari fungsi f(x) = 5x - 10 adalah...
3. Diketahui f(x) = (3x - 2) / (x + 4). Nilai dari f-1(2) adalah...
4. Jika (f ∘ g)(x) = 6x + 5 dan f(x) = 2x - 1, maka g(x) adalah...
5. Diketahui f-1(x) = x + 3 dan g-1(x) = 2x - 1. Nilai dari (f ∘ g)-1(2) adalah...

2. Penjelasan Detail: Barisan & Deret

Barisan Bilangan adalah urutan bilangan yang disusun menurut aturan atau pola tertentu. Setiap bilangan di dalamnya disebut suku (dilambangkan dengan Un). Sedangkan Deret adalah penjumlahan seluruh suku-suku pada barisan tersebut (dilambangkan dengan Sn).

  • Barisan & Deret Aritmatika: Selisih antara dua suku yang berurutan selalu tetap. Selisih tetap ini disebut Beda (b), di mana b = Un - Un-1.
  • Barisan & Deret Geometri: Perbandingan (hasil bagi) antara dua suku yang berurutan selalu tetap. Perbandingan tetap ini disebut Rasio (r), di mana r = Un / Un-1.
  • Deret Geometri Tak Hingga (S∞): Penjumlahan suku-suku geometri sampai tak terhingga banyaknya. Syarat agar memiliki nilai jumlah (konvergen) adalah rasio berada di antara -1 dan 1 (-1 < r < 1).

Kumpulan Rumus Lengkap

Aritmatika: Suku ke-n & Beda
Un = a + (n - 1)b
b = U2 - U1 = Un - Un-1
Aritmatika: Jumlah n Suku (Sn)
Sn = (n / 2)(a + Un)
Sn = (n / 2)(2a + (n - 1)b)
Aritmatika: Suku Tengah (Ut)
Ut = (a + Un) / 2
(Berlaku jika n ganjil)
Geometri: Suku ke-n & Rasio
Un = a · rn-1
r = U2 / U1 = Un / Un-1
Geometri: Jumlah n Suku (Sn)
Sn = a(rn - 1) / (r - 1)  (jika r > 1)
Sn = a(1 - rn) / (1 - r)  (jika r < 1)
Geometri: Suku Tengah & Tak Hingga
Ut = √(a · Un)
S∞ = a / (1 - r)  (-1 < r < 1)
⚡ Cara Cepat & Rumus Kilat Barisan & Deret
  • Mencari Beda (b) Jika Diketahui 2 Suku Acak (Up dan Uq):
    Tidak perlu eliminasi panjang! Langsung gunakan: b = (Up - Uq) / (p - q)
  • Mencari Rasio (r) Jika Diketahui 2 Suku Geometri Acak:
    Langsung gunakan: r(p - q) = Up / Uq
  • Hubungan Sn dan Un (Berlaku untuk SEMUA jenis deret):
    Un = Sn - Sn-1 (dan U1 = S1)
  • Trik Pantulan Bola Jatuh dari Ketinggian h0 dengan Rasio Pantulan r:
    Total Panjang Lintasan Bola sampai berhenti = h0 × (1 + r) / (1 - r) (atau 2·S∞ - h0).
  • Trik Deret Geometri Ganjil & Genap Tak Hingga:
    Rasio antara jumlah suku genap dan ganjil adalah r = Sgenap / Sganjil.

Contoh Soal & Pembahasan Bertingkat

Tingkat 1: Mudah

Soal: Diketahui barisan geometri: 3, 6, 12, 24, ... Tentukan suku ke-7 (U7)!

Pembahasan:
Suku pertama a = 3, rasio r = 6 / 3 = 2.
U7 = a · r7-1 = 3 · 26 = 3 · 64 = 192.
Tingkat 2: Sedang

Soal: Suatu barisan aritmatika memiliki U3 = 11 dan U8 = 31. Tentukan nilai suku ke-20 (U20)!

Pembahasan (Menggunakan Rumus Cepat):
1. Cari beda: b = (U8 - U3) / (8 - 3) = (31 - 11) / 5 = 20 / 5 = 4.
2. Hitung U20 dari U8: U20 = U8 + (20 - 8)b = 31 + 12(4) = 31 + 48 = 79.
Tingkat 3: Sulit (HOTS)

Soal: Sebuah bola dijatuhkan dari ketinggian 10 meter. Setiap kali menyentuh lantai, bola memantul kembali setinggi 3/5 dari ketinggian sebelumnya. Tentukan panjang seluruh lintasan bola sampai berhenti!

Pembahasan (Menggunakan Trik Bola Memantul):
Diketahui h0 = 10 dan rasio r = 3/5.
Total Lintasan = h0 × (1 + r) / (1 - r)
Total Lintasan = 10 × (1 + 3/5) / (1 - 3/5) = 10 × (8/5) / (2/5) = 10 × 4 = 40 meter.

Latihan Mandiri (5 Soal — Opsional)

1. Suku ke-15 dari barisan aritmatika 4, 7, 10, 13, ... adalah...
2. Jumlah 10 suku pertama dari deret aritmatika 2 + 6 + 10 + 14 + ... adalah...
3. Jumlah deret geometri tak hingga: 18 + 6 + 2 + 2/3 + ... adalah...
4. Diketahui jumlah n suku pertama suatu deret adalah Sn = 2n2 + 3n. Nilai suku ke-5 (U5) adalah...
5. Pada barisan geometri diketahui U2 = 6 dan U5 = 48. Suku pertama barisan tersebut adalah...

3. Penjelasan Detail: Transformasi Geometri

Transformasi Geometri adalah proses perpindahan atau perubahan posisi, arah, maupun ukuran suatu objek geometri (titik, garis, atau kurva) pada bidang koordinat Cartesius (x, y) menjadi bayangan baru (x', y').

  1. Translasi (Pergeseran): Memindahkan setiap titik dengan jarak dan arah yang sama tanpa mengubah bentuk atau ukuran.
  2. Refleksi (Pencerminan): Memindahkan titik menggunakan sifat cermin datar (jarak objek ke cermin sama dengan jarak cermin ke bayangan).
  3. Rotasi (Perputaran): Memutar titik terhadap suatu titik pusat tertentu sejauh sudut θ. Sudut positif (+) berarti berlawanan arah jarum jam, sedangkan negatif (-) searah jarum jam.
  4. Dilatasi (Perkalian/Perbesaran): Mengubah ukuran objek (memperbesar atau memperkecil) berdasarkan titik pusat dan faktor skala k.

Tabel Rumus Lengkap Transformasi Titik P(x, y)

Refleksi Terhadap Sumbu-X (garis y = 0) (x, -y)

Refleksi Terhadap Titik Asal O(0, 0) (-x, -y)
Refleksi Terhadap Garis y = x (y, x)
Refleksi Terhadap Garis y = -x (-y, -x)
Refleksi Terhadap Garis x = h (2h - x, y)
Refleksi Terhadap Garis y = k (x, 2k - y)

Rotasi O(0,0) Sudut -90° atau +270° (y, -x)

⚡ Cara Cepat & Rumus Kilat Transformasi Geometri
  • Trik Mencari Bayangan Garis / Kurva:
    1. Tentukan rumus bayangan x' dan y'.
    2. Ubah menjadi bentuk x = ... dan y = ....
    3. Substitusikan x dan y yang baru ke dalam persamaan garis/kurva awal, lalu hilangkan tanda aksen (').
  • Trik Translasi Garis Ax + By = C oleh T(a, b):
    Langsung tulis: A(x - a) + B(y - b) = C (perhatikan tanda kurang pada a dan b!).
  • Trik Luas Bangun Hasil Transformasi Matriks M:
    Jika suatu bangun datar berluas L ditransformasikan oleh matriks M (atau dilatasi skala k), maka:
    Luas Bayangan = |det(M)| × L (untuk dilatasi skala k, Luas Bayangan = k2 × L).
  • Komposisi Transformasi Matriks:
    Jika titik ditransformasi oleh M1 lalu dilanjutkan M2, perkalian matriksnya dibalik: Mtotal = M2 × M1.

Contoh Soal & Pembahasan Bertingkat

Tingkat 1: Mudah

Soal: Titik A(4, -7) dicerminkan terhadap garis y = x, kemudian ditranslasikan oleh T = (-2, 5). Tentukan koordinat bayangan akhirnya!

Pembahasan:
1. Refleksi terhadap garis y = x (tukar posisi x dan y): A(4, -7) → A'(-7, 4).
2. Translasi oleh T(-2, 5): A''(-7 + (-2), 4 + 5) = A''(-9, 9).
Tingkat 2: Sedang

Soal: Tentukan persamaan bayangan garis 2x - 3y + 6 = 0 setelah ditranslasikan oleh T = (4, -1)!

Pembahasan (Menggunakan Rumus Cepat Translasi Garis):
Substitusi x → (x - 4) dan y → (y - (-1)) = (y + 1):
2(x - 4) - 3(y + 1) + 6 = 0
2x - 8 - 3y - 3 + 6 = 0
2x - 3y - 5 = 0.
Tingkat 3: Sulit (HOTS)

Soal: Sebuah segitiga ABC memiliki luas 12 cm2. Segitiga tersebut didilatasikan dengan pusat P(2, -3) dan faktor skala k = -3, kemudian dirotasikan sejauh 90°. Berapakah luas bayangan segitiga tersebut?

Pembahasan (Menggunakan Trik Luas):
Ingat bahwa rotasi tidak mengubah luas bangun. Hanya dilatasi yang mengubah luas sebesar k2.
Luas Bayangan = k2 × Luas Awal = (-3)2 × 12 = 9 × 12 = 108 cm2.
